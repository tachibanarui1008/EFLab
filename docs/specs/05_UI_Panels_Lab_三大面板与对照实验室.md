> **负责角色**：`Agent-05 (FrontendUI)` — Stage 5  
> **代码落盘路径**：`src/ui/panels/`、`src/ui/lab/`

## 1. 模块目标与核心原则

`Agent-05` 负责将核心经济引擎（`src/core/`）与像素城市画布（`src/ui/city_canvas/`）组装为完整、直观的单页教学与实验应用（SPA）。
- **核心红线 1（不足 12 个月同比保护）**：在顶部看板、折线图 Tooltip 与对照表格中，当 `month < 12`（即 `gdpYoY === null` 或 `inflationYoY === null`）时，UI **必须显式渲染为 `"数据不足 (需满12个月)"`**，严禁显示 `0.0%`、`NaN%` 或 `undefined`。
- **核心红线 2（60 个月周期终点自动暂停）**：当模拟推进至 `month === 60` 时，自动播放定时器必须立即停止并弹出阶段总结提示，允许用户查看 60 个月完整复盘或导出 JSON 存档。
- **核心红线 3（双沙盒内存物理隔离）**：在“双轨对照实验室”中，基准组（`baselineHistory`）与干预组（`interventionHistory`）必须持有完全独立的 `SimulationState[]` 数组，任何针对干预组的滑杆调节或基建开关绝不允许污染基准组。

## 2. 全局应用框架与常驻控制栏（Global App Shell）

界面采用固定三段式结构：**顶部宏观核心指标栏（Top HUD）** + **中央主工作区（三大标签页切换）** + **底部常驻时间与政策控制栏（Bottom Control Dock）**。

### 2.1 顶部宏观核心指标栏（Top HUD Bar）
常驻展示当前激活沙盒最新月份（或历史回看选中月份）的 7 项核心指标：
1. **当前模拟时间**：`第 XX / 60 月`（附当前随机种子 `Seed: #XXXXXX` 与 SFC 配平状态绿灯徽章 `SFC 守恒 ✓`）。
2. **实际 GDP / 同比**：`XXX.X k` | 同比：`month < 12 ? "数据不足" : "+X.X%"`（环比附小字展示）。
3. **CPI 物价指数 / 同比通胀**：`XXX.X`（不含资本品）| 同比：`month < 12 ? "数据不足" : "+X.X%"`。
4. **全城综合失业率**：`XX.X%`（悬浮展开：底层工人失业率 `XX.X%` / 中层管理失业率 `XX.X%`）。
5. **市政财政状况**：财政存款 `XXX.X k` | 债务 `XXX.X / 1500.0 k` | 当月盈余/赤字 `±XX.X k`。
6. **基础银行存贷比**：总存款 `XXXX.X k` | 总贷款 `XXXX.X k`（存贷比 `XX.X% / 85.0%`）。
7. **城邦综合景气度**：`XX.X / 100`（带冷暖色进度条）。

### 2.2 底部常驻时间与政策控制栏（Bottom Control Dock）
分为左右两个功能区：
- **左侧：时间步进控制器（Time Controller）**
  - `[⏸ 暂停]` / `[▶ 单步下一月 (+1M)]` / `[▶ 1× 常速 (1200ms/月)]` / `[⏩ 3× 倍速 (400ms/月)]` / `[↺ 重置至第0月]`。
  - **时间轴进度条（Scrubber）**：支持拖拽查看已走过的 `0 ~ currentMonth` 历史快照（回看历史时画布与图表同步展示选中月状态，并提示“历史回看模式”）。
- **右侧：市政政策与冲击快捷控制台（Policy & Shock Console）**
  - **1. 基准个人所得税率 $\tau$ 单滑杆**：范围 `5% ~ 50%`（默认 `20%`）。滑杆旁实时动态预览三阶层折算税率：
    `底层工薪: (0.75τ)% | 中层工薪: (1.00τ)% | 资本家分红: (1.25τ)%`
    若修改了滑杆，显示黄色待生效徽章：`[将于第 t+1 月 Step 1 生效]`。
  - **2. 公共服务月度预算滑杆**：范围 `60k ~ 360k`（默认 `180k`，提示 `50% 民生补贴 / 50% 公务采购`），同样标注下月生效。
  - **3. 公共基建项目按钮组**：
    - `[🛣️ 道路改善工程 (6个月 | 25件资本品/月)]`：显示状态（未立项 / 施工中 `X/6月` / **⚠️ 缺钱停工** / ✅ 已竣工：物流损耗 `0.5%`）。
    - `[⚡ 能源扩容工程 (8个月 | 35件资本品/月)]`：显示状态（未立项 / 施工中 `X/8月` / **⚠️ 缺钱停工** / ✅ 已竣工：产能效率 `+8%`）。
  - **4. 外生冲击实验注入按钮**：
    - `[📉 注入：消费信心下降 (-15%, 6个月)]`
    - `[⚙️ 注入：生产效率下降 (-12%, 6个月)]`
  - **5. 存档工具**：`[📤 导出 JSON 存档]` / `[📥 导入 JSON 存档]`。

## 3. 三大核心视图面板详细设计（Three Core Panels）

### 面板一：城市主视图（City Main View）
- **左/中主区域（占宽 `70%`）**：挂载 Stage 4 交付的 `48 × 32` 东亚像素小城 Canvas，支持 `1×` / `2×` 整数倍缩放与点击建筑弹出“部门/阶层汇总数据浮层”。
- **右侧边栏（占宽 `30%`）：四部门实时资金与实物速览卡**
  - **居民三阶层对比条**：并排展示底层工人、中层管理、资本家的当月可支配收入、实际消费、强制储蓄与期末银行存款占比（直观呈现财富向高储蓄倾向资本家集中的过程及累进税的调节作用）。
  - **三行业产销存监控表**：展示食品、消费品、资本品的价格、产能利用率、管理协同系数 $\phi_{\text{mgmt}}$、期末库存及扩产触发状态。

---

### 面板二：经济解释与归因面板（Economic Explanation & Attribution Panel）
专为“看懂经济周期为什么拐头”设计，分为上下或左右联动布局：
1. **多维可打标时间序列折线图（Annotated Multi-Line Charts）**：
   - 提供 4 组标准图表切换或并排展示：
     - **图 A（宏观总量）**：实际 GDP、名义 GDP、CPI 指数、综合失业率；
     - **图 B（阶层分配与消费）**：三阶层税后可支配收入曲线、三阶层银行存款存量曲线、强制储蓄曲线；
     - **图 C（行业产销与库存周期）**：三行业实际产量 vs 市场需求量、期末库存曲线、产能利用率与 $\phi_{\text{mgmt}}$ 曲线；
     - **图 D（财政与金融闭环）**：市政税收 vs 支出、市政债务余额、银行总存款 vs 总贷款。
   - **关键事件垂直打标线（Event Markers on Timeline）**：
     折线图横轴（月份 $0 \sim 60$）上必须自动绘制垂直虚线标记点：
     - 🔵 **蓝色标记**：税率或公共预算调整正式生效月（`POLICY_ACTIVE`）；
     - 🔴 **红色标记**：外生冲击爆发与解除月（`SHOCK_TRIGGER`）；
     - 🟡 **橙色/绿色标记**：基建项目开工、**缺钱停工**、复工与竣工月（`PROJECT_STATUS`）。
2. **结构化月度事件归因流（Traceable Event Feed）**：
   - 按月份倒序或正序展示 `SimulationState.events` 卡片流。
   - 视觉上使用醒目徽章区分两类归因（严格遵循 Stage 3 规范）：
     - `[🎯 确定性机制触发]`（实心深蓝/琥珀色徽章）：展示政策生效、管理短缺打折、产能 `>85%` 触发 `5%` 扩产、缺货按比例配给、市政缺钱停工等 100% 机制锁定的因果事件。
     - `[📊 相关变化观察]`（浅灰虚线边框徽章）：展示 GDP、CPI、失业率的多因素伴随波动，并在面板顶部常驻提示：*“注：宏观总量为四部门存量-流量耦合结果，非单一触发因素的波动均标为‘相关变化’。”*

### 面板三：双轨对照实验室（Dual-Track Comparison Lab）
这是 EFLab 最核心的科研与教学功能，用于在**完全相同的初始状态与相同随机种子 `seed`** 下，对比“什么都不改（或政策方案 A）”与“施加政策干预（方案 B）”的因果分叉（Counterfactual Analysis）。

1. **双沙盒运行架构**：
   - **基准组（Baseline Sandbox）**：默认锁死第 0 月初始政策（$\tau = 20\%$，预算 $180\text{k}$，无基建），或允许用户将当前任意轨迹“设为基准组快照”。
   - **干预组（Intervention Sandbox）**：与基准组共享完全相同的 `seed`（以及任何设定为背景环境的外生冲击），但允许玩家在指定月份（例如第 12 月）修改税率 $\tau$、调整公共预算或启动基建项目。
   - **同步推进控制**：提供 `[⚡ 双轨同步推进 +1月]` 与 `[⚡ 双轨同步快进至第 60 月]` 按钮，同时调用 `stepMonth(baselineState)` 与 `stepMonth(interventionState)`。
2. **双轨分叉对比视图（Split & Overlay Comparison）**：
   - **同图双线叠加折线图（Overlay Charts）**：
     - 实线（`Solid Line`）代表**干预组（Intervention）**，虚线（`Dashed Line`）代表**基准组（Baseline）**。
     - 支持一键切换对比指标：实际 GDP、综合失业率、CPI、底层工人实际消费、资本家存款、市政债务余额、三行业库存。
   - **净政策效应差值卡（Net Treatment Effect, $\Delta = \text{Intervention} - \text{Baseline}$）**：
     - 实时计算并展示当前月及累计 60 个月的差值：
       - $\Delta \text{累计实际 GDP}$：`+XXX.X k (+X.X%)`
       - $\Delta \text{期末综合失业率}$：`-X.X 个百分点`
       - $\Delta \text{期末 CPI}$：`+X.X 点`
       - $\Delta \text{底层工人累计实际消费}$：`+XX.X k`
   - **PRNG 抗干扰一致性指示器**：
     - 在实验室面板角落展示实时校验结果：`[PRNG 同步核验：基准组与干预组第 t 月行业基础 TFP 随机扰动差值 = 0.000000 ✓]`，向使用者直观证明两条曲线的分叉 100% 来自政策干预本身，而非随机数错位！

## 4. Stage 5 守门员自检标准

`Agent-05` 在移交至 Stage 6 前必须验证：
1. **无干预双轨零分叉测试**：当基准组与干预组使用相同 `seed` 且均不施加任何政策差异时，同步推进 60 个月，两条对比曲线的差值 $\Delta$ 在所有月份严格等于 `0`。
2. **`month < 12` 同比展示检查**：检查第 `0 ~ 11` 月 UI 渲染输出，确认 `gdpYoY` 与 `inflationYoY` 均显示“数据不足”，无 `NaN` 或 `0%` 误导。
3. **存档导出与重载往返测试**：在第 30 月导出 JSON 存档并重新导入，历史折线图、事件卡片流与像素城市状态与导出前 100% 一致，继续推进至第 60 月结果不变。
